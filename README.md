# 🧾 Billing — SOLID / Open-Closed Principle

Учебный проект, демонстрирующий применение принципа **Open/Closed Principle (OCP)**
из семейства SOLID на примере системы расчёта счетов с разными типами биллинга.

Домашнее задание выполнено в ветке `8-solid` и сдаётся через
**Pull Request** в ветку `master`.

---

## 📌 Задание

Спроектировать класс `Billing` со свойством `amount` и методом `calculateTotal`
для расчёта счёта. Реализовать разное поведение `calculateTotal` для разных типов:

- **fixBilling** — возвращает `amount` как результат;
- **hourBilling** — считает `amount × число часов`;
- **itemBilling** — считает `amount × число элементов`.

Обязательное условие — соблюдение **принципа открытости/закрытости (OCP)**:
добавление нового типа счёта не должно требовать изменения существующего кода.

## 🧠 Как применён OCP

Базовый класс `Billing` задаёт **контракт**: свойство `amount` и метод
`calculateTotal()`. Каждый тип счёта — подкласс со своей реализацией расчёта.

Благодаря полиморфизму код, использующий счета (функция `formatInvoice()`),
зависит только от абстракции и работает с любым типом без `if / switch / instanceof`.

> **Классы открыты для расширения, но закрыты для модификации.**
> В качестве демонстрации в проект добавлен новый тип `DiscountBilling` —
> ни одна строка существующих классов при этом не изменена.

### Типы счетов

| Класс             | Тип             | Формула                       | Пример             |
|-------------------|-----------------|-------------------------------|--------------------|
| `FixBilling`      | fixBilling      | `amount`                      | `1000 → 1000`      |
| `HourBilling`     | hourBilling     | `amount × часы`               | `500 × 8 = 4000`   |
| `ItemBilling`     | itemBilling     | `amount × элементы`           | `100 × 5 = 500`    |
| `DiscountBilling` | discountBilling | `amount × (1 − скидка / 100)` | `1000 − 10% = 900` |

---

## 💻 Пример использования

```javascript
const fix  = new FixBilling(1000);
const hour = new HourBilling(500, 8);
const item = new ItemBilling(100, 5);

fix.calculateTotal();  // 1000
hour.calculateTotal(); // 4000
item.calculateTotal(); // 500
```

Добавление нового типа **без изменения** существующего кода:

```javascript
class DiscountBilling extends Billing {
  constructor(amount, discountPercent) {
    super(amount);
    this.discountPercent = discountPercent;
  }

  calculateTotal() {
    return this.amount * (1 - this.discountPercent / 100);
  }
}
```

## 📚 SOLID в проекте

| Принцип | Статус |
|---------|--------|
| **S** — Single Responsibility | ✅ каждый класс отвечает за один способ расчёта |
| **O** — Open/Closed | ✅ основное требование задания |
| **L** — Liskov Substitution | ✅ подклассы корректно подставляются вместо `Billing` |
| **I** — Interface Segregation | ✅ минимальный контракт: только `calculateTotal()` |
| **D** — Dependency Inversion | ✅ зависимость от абстракции, а не от конкретных типов |
